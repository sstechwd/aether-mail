# Ideas parking lot

Not a roadmap. Things said in passing. Review before building. None of these
are promised.

## Product maybe

- Command chains: “file this and always do that for this sender”
- Gmail/Outlook mail OAuth (protocol path exists; needs a registered client id)
- Search that feels like Outlook (`from: priya invoice march`)
- Calendar as a first-class month/week/day surface — later
- Optional local model via Ollama (not a GGUF inside the installer)
- OS-agnostic installers: `.dmg` / `.deb` built **on that OS** — `docs/PACKAGING.md`

## Lean no

- Inline browser / social inside the mail app (phishing + cookie jar)
- Shipping a model weight in v1 NSIS (~1GB installer, weak drafts)
- Hosted mailbox / `@aether` address
- Ads, pay-to-send, Electron
- Auto-send
- Native App Store / Play in v1
